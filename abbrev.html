📚 Справочник терминов

ГСМ — горюче-смазочные материалы (дизельное топливо, масла). Ед. изм: л/га
NPK — азот (N), фосфор (P₂O₅), калий (K₂O) — основные элементы питания растений.
д.в. — действующее вещество удобрения (чистые NPK без примесей).
ц/га — центнер на гектар (100 кг/га).
л/га — литр на гектар.
No-Till — нулевая обработка почвы (посев без вспашки).
Mini-till — минимальная обработка (дискование).
ИИ-агент — экспертная система на правилах.
REST API — архитектура веб-сервисов.
PDF/CSV — форматы экспорта документов.
